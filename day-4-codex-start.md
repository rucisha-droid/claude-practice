# Day 4 Plan: Codex Start

A simple, beginner-friendly plan for today.

## 1. Restart GitHub repo
- Open the project folder in the terminal.
- Make sure you're on the right repo: `git remote -v`

## 2. Revise git status
- Check what's changed: `git status`
- Check current branch: `git branch`

## 3. Make one small edit
- Open any file (or this one) and make a small, simple change.
- Save the file.

## 4. Commit and push
- Stage the change: `git add <file>`
- Commit it: `git commit -m "small update"`
- Push it: `git push`

## 5. Begin Codex basics
- Open Codex and read through the basic intro/getting started docs.
- Try one small example or exercise to get familiar with it.
