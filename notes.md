# What I Learned Today — Claude Code

**Date:** 2026-06-24

1. **How to install and launch Claude Code** — Used `npm install -g @anthropic-ai/claude-code` to install it and `claude` to launch it inside a project folder from the terminal.

2. **Basic terminal commands before editing** — Learned to always run `git status` and work on a separate branch before letting Claude make any changes, so edits stay reversible.

3. **How to create files with Claude Code** — Asked Claude to create `study-plan.md` directly from a prompt, without writing any code myself.

4. **How to read files in the terminal** — Used `cat filename.md` to display file contents right inside the terminal without opening any app.

5. **How to organize a practice workspace** — Set up a dedicated folder (`claude-practice`) on the Desktop to safely experiment with Claude Code without risking real project files.
